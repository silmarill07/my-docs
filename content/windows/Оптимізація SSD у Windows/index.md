## Увімкнення TRIM

Перевірте, чи активована функція TRIM:

```cmd id="n17swu"
fsutil behavior query disabledeletenotify
```

> [!NOTE]
> Якщо команда повернула `0` — TRIM уже увімкнений.
>
> Якщо повернула `1` — його потрібно активувати.

Для увімкнення TRIM виконайте:

```cmd id="nk9f4n"
fsutil behavior set disabledeletenotify NTFS 0
```

---

## Вимкнення автоматичної дефрагментації

Відкрийте:

`Диск C → Властивості → Сервіс → Оптимізувати`

Після цього вимкніть **оптимізацію за розкладом**.

> [!IMPORTANT]
> Для SSD достатньо періодичного виконання TRIM. Регулярна дефрагментація не потрібна.

---

## Вимкнення індексації файлів

Відкрийте:

`Диск C → Властивості`

Зніміть прапорець:

`Дозволити індексувати вміст файлів на цьому диску`

Підтвердьте застосування змін до всіх файлів і папок.

> [!TIP]
> Якщо ви рідко користуєтеся пошуком Windows, вимкнення індексації може трохи зменшити кількість операцій запису на SSD.

---

## Увімкнення кешування запису

Відкрийте:

`Диспетчер пристроїв → Дискові пристрої`

Клацніть правою кнопкою миші по SSD та відкрийте:

`Властивості → Політика`

Увімкніть параметр:

`Дозволити кешування запису на пристрої`

> [!WARNING]
> На ноутбуках і ПК без джерела безперебійного живлення вимикати буферне очищення кешу запису не рекомендується, оскільки це може призвести до втрати даних у разі раптового вимкнення живлення.
