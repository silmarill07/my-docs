Windows містить вбудовані засоби віртуалізації, які дозволяють запускати віртуальні машини та ізольоване середовище **Windows Sandbox**. За замовчуванням ці компоненти можуть бути вимкнені.

> [!NOTE]
> Для використання Hyper-V і Windows Sandbox процесор повинен підтримувати апаратну віртуалізацію (Intel VT-x або AMD-V), а сама функція має бути увімкнена в BIOS/UEFI.

## Крок 1. Відкрийте вікно компонентів Windows

Натисніть комбінацію клавіш **Win + R**, введіть команду:

```text id="u91myd"
optionalfeatures
```

та натисніть **Enter**.

---

## Крок 2. Увімкніть необхідні компоненти

У списку компонентів встановіть прапорці біля таких пунктів:

* **Hyper-V**
* **Virtual Machine Platform**
* **Windows Hypervisor Platform**
* **Windows Sandbox**

> [!IMPORTANT]
> Якщо пункт **Hyper-V** відсутній, можливо, використовується редакція Windows Home. У такому випадку Windows Sandbox і Hyper-V можуть бути недоступні без додаткових дій.

---

## Крок 3. Перезавантажте комп'ютер

Після підтвердження змін Windows встановить необхідні компоненти та запропонує перезавантажити комп'ютер.

> [!TIP]
> Після перезавантаження **Hyper-V Manager** можна знайти через меню «Пуск», а **Windows Sandbox** буде доступна як окрема програма.

## Підсумок

Після увімкнення компонентів система буде готова до використання Hyper-V для створення віртуальних машин і Windows Sandbox для безпечного запуску програм в ізольованому середовищі.
