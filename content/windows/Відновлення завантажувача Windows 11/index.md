Якщо Windows 11 перестала завантажуватися через пошкоджений або відсутній завантажувач, його можна відновити за допомогою інсталяційного носія.

## Завантаження з інсталяційного носія

Завантажтеся з інсталяційної флешки Windows через **Boot Menu**.

На екрані вибору мови натисніть:

```text
Shift + F10
```

Відкриється командний рядок.

---

## Підготовка EFI-розділу

Запустіть утиліту керування дисками:

```cmd
diskpart
```

Перегляньте список дисків:

```cmd
list disk
```

Виберіть диск, на якому встановлена Windows:

```cmd
select disk 2
```

> [!NOTE]
> Замініть `2` на номер вашого диска.

Перегляньте список розділів:

```cmd
list volume
```

Знайдіть EFI-розділ (FAT32, приблизно 100–500 МБ) та виберіть його:

```cmd
select volume X
```

Призначте йому літеру:

```cmd
assign letter=Z
```

Вийдіть із DiskPart:

```cmd
exit
```

---

## Відновлення завантажувача

Виконайте команду:

```cmd
bcdboot D:\Windows /s Z: /f UEFI
```

> [!NOTE]
> `D:` — літера розділу, на якому встановлена Windows.
>
> `Z:` — літера EFI-розділу, призначена на попередньому кроці.

---

## Завершення

Закрийте командний рядок, вийміть інсталяційну флешку та перезавантажте комп'ютер.

> [!WARNING]
> Якщо EFI-розділ відсутній або не відображається, його можна створити вручну:
>
> ```cmd
> select partition X
> shrink desired=300
> create partition efi size=300
> format quick fs=fat32 label="System"
> assign letter=Z
> exit
> bcdboot D:\Windows /s Z: /f UEFI
> ```
>
> Перед виконанням команд замініть `X` на номер розділу з Windows, а `D:` — на фактичну літеру системного диска.
