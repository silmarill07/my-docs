Після перевстановлення або видалення дистрибутива Linux в EFI-розділі можуть залишитися його завантажувачі. Вони займають місце та іноді спричиняють появу зайвих пунктів у меню завантаження.

У цій інструкції показано, як безпечно видалити непотрібні завантажувачі Linux за допомогою командного рядка Windows.

> [!WARNING]
> Видаляйте **лише** папки тих дистрибутивів Linux, які більше не використовуються. Не видаляйте папки **Microsoft**, **Boot** або інші, призначення яких вам невідоме.

## Крок 1. Відкрийте командний рядок від імені адміністратора

Запустіть **CMD** або **Термінал Windows** з правами адміністратора та виконайте:

```bash
diskpart
```

> Запускає утиліту для керування дисками.

Далі перегляньте список фізичних дисків:

```bash
list disk
```

> Відображає всі підключені накопичувачі.

Виберіть диск, на якому встановлено Windows:

```bash
sel disk 2
```

> Замініть `2` на номер свого диска.

Перегляньте список розділів:

```bash
list vol
```

> Відображає всі томи на вибраному диску.

Виберіть EFI-розділ:

```bash
sel vol 3
```

> Замініть `3` на номер EFI-розділу.

Призначте йому тимчасову літеру:

```bash
assign letter=U:
```

> Після цього EFI-розділ стане доступним через Провідник та командний рядок.

Вийдіть із DiskPart:

```bash
exit
```

## Крок 2. Перейдіть до EFI-розділу

Відкрийте призначений диск:

```bash
U:
```

Переконайтеся, що розділ відкрився:

```bash
dir
```

Перейдіть до каталогу EFI:

```bash
cd EFI
```

Перегляньте його вміст:

```bash
dir
```

> [!TIP]
> Зазвичай тут знаходяться папки на кшталт `ubuntu`, `fedora`, `Manjaro`, `LinuxMint`, а також системні папки `Microsoft` і `Boot`.

## Крок 3. Видаліть непотрібний завантажувач

Виконайте команду:

```bash
rmdir /S ubuntu
```

> Замініть `ubuntu` на назву папки потрібного дистрибутива. Після підтвердження папку буде повністю видалено.

## Перевірка

Після видалення можна ще раз виконати:

```bash
dir
```

і переконатися, що папка більше не відображається.

> [!IMPORTANT]
> Якщо після видалення запис Linux усе ще присутній у меню завантаження UEFI, його потрібно окремо видалити зі списку завантажувальних записів BIOS/UEFI або за допомогою утиліти `bcdedit` чи інших спеціалізованих інструментів.

## Підсумок

Після виконання цих дій EFI-розділ буде очищено від непотрібних завантажувачів Linux. Це допоможе уникнути зайвих записів у меню завантаження та спростить керування системою.
