Якщо **Microsoft Defender** працює некоректно, не запускається або видає помилки, насамперед рекомендується перевірити та відновити системні файли Windows.

## Відновлення системних файлів

Запустіть **Командний рядок** або **Windows Terminal** від імені адміністратора та виконайте команду:

```bash
DISM /Online /Cleanup-Image /RestoreHealth
```

Ця команда перевірить сховище компонентів Windows та автоматично відновить пошкоджені файли, якщо це можливо.

> [!NOTE]
> Виконання команди може тривати від кількох хвилин до пів години залежно від швидкості комп'ютера.

## Перевірка цілісності системних файлів

Після завершення роботи DISM виконайте:

```bash
sfc /scannow
```

Команда **System File Checker (SFC)** просканує всі захищені системні файли Windows і автоматично замінить пошкоджені або відсутні файли.

> [!TIP]
> Для найкращого результату рекомендується спочатку виконати команду **DISM**, а після її завершення — **SFC**.

> [!IMPORTANT]
> Якщо після завершення перевірки були виправлені помилки, перезавантажте комп'ютер і перевірте, чи зникли проблеми з Microsoft Defender.
