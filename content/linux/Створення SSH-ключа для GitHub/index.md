SSH-ключі дозволяють безпечно підключатися до GitHub без необхідності щоразу вводити логін і пароль. Нижче наведено просту інструкцію зі створення та налаштування SSH-ключа.

## Створення SSH-ключа

Виконайте команду, замінивши `your-email@example.com` на адресу електронної пошти, прив'язану до вашого GitHub-акаунта:

```bash
ssh-keygen -t ed25519 -C "your-email@example.com"
```

Під час створення ключа:

- натисніть **Enter**, щоб зберегти ключ у стандартному каталозі (`~/.ssh/id_ed25519`);
- за бажанням задайте парольну фразу (passphrase) для додаткового захисту.

## Перегляд відкритого ключа

Після створення ключа виконайте:

```bash
cat ~/.ssh/id_ed25519.pub
```

Скопіюйте весь виведений текст.

## Додавання ключа до GitHub

1. Відкрийте **GitHub**.
2. Перейдіть до **Settings → SSH and GPG keys**.
3. Натисніть **New SSH key**.
4. Вкажіть довільну назву ключа (наприклад, *My Laptop*).
5. Вставте скопійований відкритий ключ у поле **Key**.
6. Натисніть **Add SSH key**.

## Перевірка підключення

Виконайте команду:

```bash
ssh -T git@github.com
```

> [!TIP]
> Під час першого підключення система може запитати підтвердження справжності сервера. Введіть `yes` і натисніть **Enter**.

Якщо все налаштовано правильно, ви побачите приблизно таке повідомлення:

```text
Hi your-github-username! You've successfully authenticated, but GitHub does not provide shell access.
```

> [!IMPORTANT]
> Повідомлення **"You've successfully authenticated"** означає, що SSH-ключ успішно додано до GitHub і підключення працює коректно.
