За замовчуванням деякі операції з дисками в Linux можуть вимагати введення пароля адміністратора. За допомогою правила **Polkit** можна дозволити користувачам із певної групи монтувати диски без додаткового підтвердження.

Цей спосіб використовує службу **UDisks2**, яка відповідає за керування дисками та їх монтування в графічному середовищі.

> [!WARNING]
> Налаштування дозволяє користувачам із групи `wheel` виконувати операції з дисками без пароля. Використовуйте його лише на власній системі.

## 1. Створіть правило Polkit

Відкрийте термінал та створіть файл:

```bash
sudo nano /etc/polkit-1/rules.d/10-udisks2.rules
```

## 2. Додайте правило

Вставте наступний код:

```javascript
polkit.addRule(function(action, subject) { 
    if (action.id.indexOf("org.freedesktop.udisks2.") == 0 && 
        subject.isInGroup("wheel")) { 
        return polkit.Result.YES; 
    }
});
```

> [!NOTE]
> Правило дозволяє всім користувачам, які входять до групи `wheel`, виконувати операції UDisks2 без запиту пароля.

Збережіть файл:

* `Ctrl + O` — записати зміни
* `Enter` — підтвердити ім'я файлу
* `Ctrl + X` — вийти з редактора

## 3. Перезавантажте систему

Для застосування змін виконайте:

```bash
sudo reboot
```

## Перевірка роботи

Після перезавантаження спробуйте підключити диск через файловий менеджер або інший графічний інструмент. Запит пароля більше не повинен з'являтися.

> [!TIP]
> Переконайтеся, що ваш користувач входить до групи `wheel`. Перевірити це можна командою:

```bash
groups
```

## Підсумок

Після створення правила Polkit система дозволить монтувати диски без пароля для користувачів із групи `wheel`, що робить роботу із зовнішніми накопичувачами швидшою та зручнішою.
