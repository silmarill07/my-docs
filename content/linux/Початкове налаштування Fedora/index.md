Після встановлення Fedora система вже готова до роботи, але кілька додаткових налаштувань зроблять її зручнішою: прискорять роботу менеджера пакетів, додадуть необхідні репозиторії, кодеки, підтримку Flatpak та корисні інструменти для GNOME.

> [!TIP]
> Перед виконанням налаштувань рекомендується зробити повне оновлення системи, щоб усі подальші зміни застосовувалися до актуальної версії пакетів.

## Налаштування DNF

DNF — це стандартний менеджер пакетів Fedora. Його можна оптимізувати, щоб прискорити завантаження та встановлення програм.

Відкрийте файл конфігурації:

```bash
sudo nano /etc/dnf/dnf.conf
```

Додайте ці параметри у розділ `[main]`:

```ini
fastestmirror=True
max_parallel_downloads=10
defaultyes=True
exclude=.ru
keepcache=True
```

> [!NOTE]
> `fastestmirror=True` автоматично вибирає найшвидше доступне дзеркало.
>
> `max_parallel_downloads=10` дозволяє DNF завантажувати до 10 пакетів одночасно замість одного.
>
> `defaultyes=True` робить натискання Enter у запитах підтвердження автоматичною відповіддю "Так".
>
> `keepcache=True` зберігає вже завантажені пакети, щоб не завантажувати їх повторно.
>
> `exclude=.ru` блокує використання дзеркал із доменом `.ru`.

## Оновлення системи

Перед встановленням додаткових пакетів потрібно переконатися, що система оновлена:

```bash
sudo dnf -y update
```

Після завершення рекомендується перезавантажити систему, особливо якщо оновлювалося ядро Linux.

# RPM Fusion та мультимедійні кодеки

Fedora за замовчуванням обмежує доступ до деяких пакетів через ліцензійні обмеження. Репозиторій RPM Fusion додає необхідне програмне забезпечення: кодеки, драйвери NVIDIA, Steam, Discord та інші програми.

> [!IMPORTANT]
> Для повноцінного використання Fedora RPM Fusion практично необхідний.

Встановіть безкоштовний та пропрієтарний репозиторії:

```bash
sudo dnf install https://mirrors.rpmfusion.org/free/fedora/rpmfusion-free-release-$(rpm -E %fedora).noarch.rpm https://mirrors.rpmfusion.org/nonfree/fedora/rpmfusion-nonfree-release-$(rpm -E %fedora).noarch.rpm
```

## Заміна ffmpeg-free на повну версію ffmpeg

Fedora постачається з обмеженим пакетом `ffmpeg-free`. Для підтримки більшої кількості форматів потрібно замінити його:

```bash
sudo dnf swap ffmpeg-free ffmpeg --allowerasing
```

Після цього оновіть мультимедійні компоненти:

```bash
sudo dnf group upgrade multimedia
```

> [!WARNING]
> Після заміни `ffmpeg-free` на `ffmpeg` рекомендується перезавантажити систему. Деякі програми GNOME можуть продовжувати використовувати старі бібліотеки до завершення поточної сесії.

Оновіть метадані AppStream:

```bash
sudo dnf group upgrade core
```

> [!TIP]
> Якщо після заміни пакетів перестали відкриватися «Файли», «Термінал» або інші програми GNOME — спочатку виконайте перезавантаження. Часто проблема пов'язана лише зі старими бібліотеками у поточній сесії.

# Налаштування Flatpak

Fedora підтримує Flatpak, але не завжди всі сторонні джерела увімкнені після встановлення.

Додайте Flathub:

```bash
flatpak remote-add --if-not-exists flathub https://dl.flathub.org/repo/flathub.flatpakrepo
```

> [!NOTE]
> Використовуйте лише системний режим Flatpak. Не додавайте Flathub одночасно через `--system` та `--user`, оскільки це може створити дублікати програм у центрі програмного забезпечення.

---

# Підтримка AppImage

Для запуску програм у форматі AppImage встановіть бібліотеку FUSE:

```bash
sudo dnf install fuse-libs
```

---

# GNOME Tweaks та розширення

Fedora використовує майже чистий GNOME, що добре для стабільності, але деякі додаткові налаштування можуть зробити систему зручнішою.

Встановіть GNOME Tweaks:

```bash
sudo dnf install gnome-tweaks
```

За допомогою нього можна змінювати:

* поведінку вікон;
* шрифти;
* анімації;
* автозапуск програм;
* додаткові параметри GNOME.

Для керування розширеннями встановіть Extension Manager:

```bash
flatpak install flathub com.mattjakeman.ExtensionManager
```

> [!TIP]
> Extension Manager дозволяє переглядати, встановлювати та оновлювати розширення GNOME через зручний графічний інтерфейс.

# Підсумок

Після виконання цих кроків Fedora буде готова для щоденного використання: DNF працюватиме швидше, з'являться необхідні репозиторії, мультимедійні кодеки, підтримка Flatpak та додаткові інструменти для налаштування GNOME.
