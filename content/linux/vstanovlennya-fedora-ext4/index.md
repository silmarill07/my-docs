# Підготовка диска та встановлення Fedora

## Завантаження в Live-систему

Завантажтеся з інсталяційного носія Fedora та виберіть режим **Live**.

---

## Встановлення GParted

Для розмітки диска встановіть GParted:

```bash
sudo dnf install gparted -y
```

Після завершення встановлення відкрийте **GParted**.

---

## Розмітка диска

### Створення таблиці розділів

У верхньому меню відкрийте:

`Device → Create Partition Table`

Як тип таблиці розділів виберіть:

```text
gpt
```

---

### Створення EFI-розділу

Створіть перший розділ із такими параметрами:

* **Розмір:** `550 MiB`
* **Назва розділу:** `EFI Partition System`
* **Файлова система:** `FAT32`
* **Мітка:** `efi`

---

### Створення розділу `/boot`

Створіть другий розділ із такими параметрами:

* **Розмір:** `1014 MiB`
* **Назва розділу:** `BOOT`
* **Файлова система:** `ext4`
* **Мітка:** `boot`

---

### Створення кореневого розділу

Використайте весь вільний простір, що залишився:

* **Розмір:** увесь доступний простір
* **Назва розділу:** `ROOT`
* **Файлова система:** `ext4`
* **Мітка:** `root`

Після створення всіх розділів застосуйте внесені зміни.

---

### Налаштування EFI-розділу

Виділіть EFI-розділ та відкрийте:

`Partition → Manage Flags`

Установіть прапорець:

```text
esp
```

Після цього для розділу автоматично буде встановлено прапорці `boot` та `esp`.

---

## Встановлення Fedora

Запустіть програму встановлення Fedora та виконайте стандартні кроки.

На етапі **Метод встановлення** виберіть:

```text
Призначення точки монтування
```

Після цього призначте точки монтування для створених розділів:

* **`/`** → `ROOT`
* **`/boot`** → `BOOT`
* **`/boot/efi`** → `EFI`

Після завершення налаштування можна розпочати встановлення операційної системи.
