>[!TIP]
>Якщо після оновлення системи або браузера Microsoft Edge почав працювати нестабільно, спробуйте запускати його через X11. У більшості випадків це допомагає усунути графічні артефакти, мерехтіння та інші проблеми, пов'язані з Wayland.

## Як це зробити

1. Відкрийте **Властивості** ярлика Microsoft Edge.
2. У полі **Аргумент командного рядка** додайте:

```text
--ozone-platform=x11 %U
```

3. Збережіть зміни та перезапустіть браузер.

Після виконання цих дій Microsoft Edge використовуватиме X11, що забезпечує стабільнішу роботу на деяких Linux-дистрибутивах.
